# teguma

Figma 오픈소스 프로젝트 컬렉션. Figma를 오픈소스로 재현하거나 대체하는 프로젝트들을 조사·수집·분류한다.

## 목표

- Figma 관련 오픈소스 프로젝트 전수 조사
- 라이선스·기능·기술 스택·활발도 기준 분류
- 수집 데이터의 구조화 및 검색 가능한 카탈로그 구축

## 운영환경

[AGENTS.md](./AGENTS.md) 참조 — 이슈 기반 개발, semver 릴리스, 자동 리뷰 파이프라인.

## 디렉토리

| 경로 | 용도 |
|------|------|
| `docs/research/` | 리서치 결과물 |
| `docs/specs/` | 기획·명세 |
| `docs/releases/` | 버전별 업데이트 리포트 |
| `data/` | 수집 데이터 (JSON/YAML) |
| `scripts/` | 자동화 스크립트 |
