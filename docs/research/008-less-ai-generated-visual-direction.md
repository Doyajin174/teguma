# AI 특유의 시각 단서를 줄이는 홍보 이미지 방향

> 조사일: 2026-07-31

## 결론

`AI 티`는 작은 손가락 오류만의 문제가 아니다. 현실보다 과장된 조명과 색, 물리적으로 설명되지 않는 장식, 어디서나 본 듯한 기술 비유, 지나치게 완벽한 재질과 템플릿 타이포가 함께 나타날 때 더 강하게 느껴진다.

이번 v2는 생성 사실을 숨기거나 탐지기를 우회하려는 작업이 아니다. 생성형 자산임을 manifest에 계속 공개하면서, 광고 이미지로서의 구체성·물리적 설득력·편집 완성도를 높이는 작업이다.

## v1 진단

| 단서 | v1에서 보인 문제 | v2 조치 |
|---|---|---|
| 과도한 스타일 | 청록·보라 네온, blue-hour, glossy 재질 | 자연광·현실적인 혼합광, 중립 화이트밸런스 |
| 기능적 불가능성 | 떠다니는 영상 카드와 추상 UI | 실제 책상 위 노트북·휴대전화·케이블 |
| 물리 오류 위험 | 에너지 궤적, LiDAR 원형 광선 | 설치된 충전기·센서 자체를 촬영하고 VFX 금지 |
| 흔한 AI 비유 | `AI = 빛나는 데이터 흐름` 반복 | 작업 현장과 제품 사용 맥락을 직접 보여줌 |
| 템플릿 과잉 | 필 태그, 외곽선, 거대한 디스플레이 글자 | IBM Plex Sans KR, 직선 그리드, 얇은 규칙선 |
| 색의 동조 | 배경·피사체·타이포가 한 색으로 물듦 | 사진의 고유색을 유지하고 강조색은 한 곳에만 사용 |

## 근거

### 사람이 알아채는 생성 이미지 단서

[CHI 2025의 대규모 실험](https://arxiv.org/abs/2502.11989)은 50,444명에게서 약 75만 건의 관찰을 수집했다. 연구가 분류한 주요 단서는 다음과 같다.

- 지나치게 glossy, waxy, picturesque, cinematic한 스타일
- 실제로 작동할 수 없는 물체와 관계
- 광원과 맞지 않는 그림자·반사
- 뒤틀린 깊이·원근과 서로 다른 해상도로 붙인 듯한 경계
- 인간의 큐레이션과 구체적인 프롬프트가 품질에 큰 영향을 준다는 점

[생성 이미지 색 통계 연구](https://pubmed.ncbi.nlm.nih.gov/40793515/)는 8,400장을 비교해 AI 이미지가 실제 이미지보다 hue·chroma·lightness 조율 범위가 좁고 물체와 배경 색의 상관이 높다고 보고했다. 따라서 전체 화면을 한 가지 네온 컬러로 물들이는 방식은 피한다.

### 신뢰받는 기업 사진

[Nielsen Norman Group의 기업 사이트 연구](https://media.nngroup.com/media/reports/free/Presenting_Company_Information_on_Corporate_Websites_3rd_Edition.pdf)는 실제 조직과 제품 맥락을 반영하는 사진, 명확한 초점, 적은 배경 방해 요소를 권하고 posed 또는 전형적인 stock처럼 보이는 사진을 피하라고 권한다.

[IBM Photography 가이드](https://www.ibm.com/design/language/photography/tips-and-techniques)는 이번 방향과 특히 잘 맞는다.

- 자연스러운 눈높이 또는 오버헤드 시점
- 자연광 또는 자연광을 모사한 현실적인 조명
- 맥락을 유지하는 깊은 초점
- color wash, glare, 인위적인 합성 효과 금지
- 추상적 기술 비유보다 실제 일하는 세계를 보여주기
- 한 개의 분명한 초점과 균형 잡힌 비대칭

### 타이포그래피

[IBM Plex](https://github.com/IBM/plex)는 OFL 1.1로 배포되며 한국어를 지원한다. [IBM 타입 가이드](https://www.ibm.com/design/language/typography/typeface/)가 설명하듯 UI와 인쇄 매체 양쪽에서 작동하는 중립적인 workhorse라서, 강한 개성을 앞세운 Black Han Sans보다 이번 에디토리얼 방향에 적합하다.

## 생성 프롬프트 원칙

1. `photorealistic`보다 `observational`, `documentary`, `field report`처럼 촬영자의 태도를 먼저 지정한다.
2. 카메라는 눈높이 35–50mm, 깊은 초점, 한 개의 일관된 광원으로 제한한다.
3. 먼지, 마모, 케이블 무게, 종이 모서리처럼 평범한 물리 단서를 포함한다.
4. 한 장면에 한 가지 업무와 한 개의 초점만 둔다.
5. 네온, 홀로그램, 떠다니는 UI, blue-hour, cinematic grade, shallow bokeh를 명시적으로 금지한다.
6. 생성된 글자와 로고는 사용하지 않고 결정론적 SVG 레이어에서 합성한다.

## 편집 디자인 원칙

- 그라디언트, 드롭섀도, 텍스트 외곽선, 둥근 필 태그를 사용하지 않는다.
- 사진 위 글자가 필요하면 불투명한 면을 사용하고, 사진 자체에 색 보정을 덮지 않는다.
- IBM Plex Sans KR Regular/SemiBold 두 굵기만 사용한다.
- 한 시안의 강조색은 하나, 장식선은 최대 두 개로 제한한다.
- 제목 크기는 v1보다 낮추고 정보 계층을 여백과 정렬로 만든다.

## 수용 기준

- 광원, 그림자, 반사, 원근, 설치 방식이 눈으로 설명 가능하다.
- VFX 없이도 회사가 무슨 일을 하는지 장면으로 이해된다.
- 5초 이상 확대해 봐도 기능적으로 불가능한 관계가 없다.
- 최종 SVG에 gradient, filter, drop shadow, text stroke, rounded pill이 없다.
- 생성 원본과 프롬프트·해시·파생 관계가 별도 스톡 manifest에 남는다.
