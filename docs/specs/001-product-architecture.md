## 한 줄 정의

**AI 에이전트가 브랜드 컨텍스트를 유지하면서 Penpot 디자인을 읽고 쓸 수 있게 하는 MCP 서버 + 디자인 시스템 브릿지.**

## 해결 전략

```
┌─────────────────────────────────────────────────────┐
│  AI Agent (Claude Code / Cursor / Codex)            │
└────────────────────┬────────────────────────────────┘
                     │ MCP Protocol
┌────────────────────▼────────────────────────────────┐
│  teguma MCP Server                                  │
│  ┌──────────────┐ ┌──────────────┐ ┌─────────────┐ │
│  │ Brand Context│ │ Design Token │ │ Layout      │ │
│  │ Engine       │ │ Compressor   │ │ Constraints │ │
│  └──────────────┘ └──────────────┘ └─────────────┘ │
└────────────────────┬────────────────────────────────┘
                     │ Penpot API
┌────────────────────▼────────────────────────────────┐
│  Penpot (self-hosted or cloud)                      │
│  - Components  - Pages  - Design Tokens  - Assets   │
└─────────────────────────────────────────────────────┘
```

### 핵심 모듈

1. **Brand Context Engine** — 디자인 시스템을 "압축 표현"으로 변환
   - 입력: Penpot 파일, DESIGN.md, 토큰 JSON, 스크린샷
   - 출력: AI가 소화 가능한 구조화된 컨텍스트 (토큰 수 1/10로)
   - Figma .fig 파일 임포트 지원 (→ Penpot 네이티브 변환)

2. **Design Token Compressor** — 전체 CSS 대신 토큰+구조만 전달
   - 색상: 팔레트 이름 + 값 (전체 CSS 변수 나열 아님)
   - 타이포: 스케일 정의 (모든 폰트 사이즈 나열 아님)
   - 간격: 기반 단위 + 배수
   - 컴포넌트: 이름 + 변형 목록 + 제약 조건

3. **Layout Constraints Mapper** — Figma Auto Layout ≒ Penpot Flex Layout 매핑
   - 프레임 경계, 반응형 브레이크포인트를 AI에 전달
   - AI가 생성한 결과물이 뷰포트 밖으로 나가지 않도록 가드레일

4. **Bidirectional Sync** — 코드 ↔ 디자인 양방향
   - AI가 Penpot에 직접 컴포넌트 생성/수정
   - Penpot 변경사항을 코드 컨텍스트로 역전파

## 기술 스택

- **언어**: TypeScript (MCP SDK 표준)
- **MCP SDK**: @modelcontextprotocol/sdk
- **Penpot 연동**: Penpot REST API + Plugin API
- **테스트**: Vitest
- **패키지**: npm (npx로 실행 가능)
