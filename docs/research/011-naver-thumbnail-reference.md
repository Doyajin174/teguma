# 네이버 블로그 실노출 썸네일 조사

> 조사일: 2026-07-31
>
> 관련 이슈: [#11](https://github.com/Doyajin174/teguma/issues/11)

## 결론

네이버 블로그 대표 이미지는 1080px 포스터가 아니라 작은 목록 표지다. 검색 결과에서는 제목이 이미지 밖에 이미 노출되므로, 썸네일은 내용을 반복 설명하기보다 피사체를 즉시 식별시키는 역할을 해야 한다.

v2는 본문 히어로·브랜드 포스터로는 유효하지만 네이버 진입용 대표 이미지로는 정보 밀도가 과도하다. v3는 한 피사체와 한 문구만 남긴다.

## 실화면 관찰

2026-07-31 네이버 PC·모바일 검색에서 `전기차 충전` 결과를 직접 측정했다.

- PC 검색 결과 대표 이미지: 104×104px
- 390px 모바일 검색 결과 대표 이미지: 104×104px
- 게시글 제목과 요약은 썸네일 밖에 별도로 노출
- 텍스트가 많은 포스터형 대표 이미지는 큰 단어 한두 개를 제외하면 식별 불가
- 사진 또는 단순한 제품 일러스트는 작은 크기에서도 소재가 즉시 식별됨

관찰 URL: [네이버 모바일 검색](https://m.search.naver.com/search.naver?where=m_view&query=%EC%A0%84%EA%B8%B0%EC%B0%A8%20%EC%B6%A9%EC%A0%84)

## 네이버 공식 자료

### 대표 사진과 앨범형

[대표 사진 설정 안내](https://help.naver.com/service/5593/contents/15464?lang=ko)에 따르면 게시글에 첨부한 이미지 중 대표 섬네일을 지정할 수 있고, 이미지 한 장만 첨부하면 자동으로 대표 이미지가 된다.

[앨범형 게시판 안내](https://help.naver.com/service/5593/contents/15235?lang=ko&osType=PC)는 기본 섬네일 비율을 1:1 정방형으로 설명한다. 따라서 핵심 피사체를 중앙 80% 안에 유지해야 한다.

### 홈·추천 피드

[블로그 홈 기능 안내](https://help.naver.com/service/5593/contents/24610?lang=ko&osType=COMMONOS)의 공식 예시는 큰 사진과 외부 제목·본문 요약을 결합한다. 사진 자체에는 제목을 반복하지 않는다.

네이버 블로그팀의 [클릭을 부르는 타이틀과 썸네일 만드는 법](https://blog.naver.com/blogpeople/223469921471)을 인용한 [한국경제 보도](https://v.daum.net/v/4RPM6JmeCk)는 다음을 전한다.

- 눈에 띄는 핵심 이미지 한 장 사용
- 사진 위 텍스트가 많으면 주목도 저하
- 두 장 이상 분할한 이미지 지양
- 상하가 부자연스럽게 크롭되는 이미지 지양
- 제목은 짧고 직관적으로 작성

## v2 축소 진단

1080px v2를 104px로 축소하면 배율은 약 9.63%다.

| 요소 | 1080px 원본 | 104px 환산 | 판정 |
|---|---:|---:|---|
| 주요 헤드라인 | 34–61px | 3.3–5.9px | 읽기 어려움 |
| 본문·목록 | 14–20px | 1.3–1.9px | 읽을 수 없음 |
| 좌측 정보 패널 | 너비 42–43% | 약 44px | 사진 식별 면적 낭비 |

## 관찰된 패턴

1. 여행·맛집·일상형은 텍스트 없이 한 장의 실제 사진을 사용한다.
2. 정보형은 텍스트를 쓰더라도 한 개의 큰 키워드나 숫자만 살아남는다.
3. 회사·제품형은 제품 클로즈업이나 단순한 기능 장면을 쓰고 상세 설명은 외부 제목에 맡긴다.
4. 포스터처럼 로고·본문·CTA·세부 목록을 모두 넣은 이미지는 104px에서 의미가 사라진다.

## v3 제작 규칙

- 한 장면, 한 피사체, 한 문구
- 피사체 점유율 60–75%
- 문구는 공백 포함 12자 이하, 한 줄
- 1080px 원본 글자 크기 120px 이상 → 104px에서 약 11.5px 이상
- 오버레이 면적 18% 이하
- 외부 제목은 포스트의 구체적인 질문이나 효용을 설명
- 104×104, 1:1, 중앙 16:9 크롭을 모두 자동 검수
- v2는 삭제하지 않고 본문 히어로/브랜드 포스터로 유지
