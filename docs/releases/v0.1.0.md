# v0.1.0 업데이트 리포트
> 릴리스일: 2026-07-30

## What Changed

- AI 에이전트가 Penpot 디자인을 읽을 수 있는 MCP 서버를 추가했습니다.
- 브랜드 컨텍스트 압축 엔진을 구현해 색상 역할, 타이포그래피 스케일, 간격 단위와 컴포넌트 구조를 토큰 효율적인 형식으로 제공합니다.
- `get_design_context`, `get_tokens`, `get_components` 도구를 추가했습니다.
- `get_constraints`를 통해 레이아웃 가드레일(MUST/MUST NOT)을 제공합니다.
- `create_element` 쓰기 도구를 추가해 Penpot 페이지에 도형과 텍스트를 생성할 수 있습니다.
- Penpot HTTP RPC 클라이언트와 재시도 로직(최대 3회, 지수 백오프)을 보강했습니다.
- Docker 멀티스테이지 빌드와 GitHub Actions 기반 테스트·릴리스 CI를 추가했습니다.
- `serializeForLLM` 직렬화와 compressor 단위 테스트 10개를 추가했습니다.
- Figma 오픈소스 랜드스케이프, 커뮤니티 페인포인트, Figma+Claude Design 비교 벤치마크 리서치를 문서화했습니다.
