# v0.2.0 릴리스 리포트

릴리스 날짜: 2026-07-30

## What Changed

이번 릴리스는 teguma MCP 서버에 Penpot 쓰기 기능과 Figma 임포트 브릿지를 추가하고, CLI·배포·검증 기반을 정비했습니다.

- M2 쓰기 도구를 추가했습니다.
  - `create_element`: Penpot 페이지에 도형·텍스트·보드를 생성합니다.
  - `get_constraints`: 레이아웃 가드레일의 MUST / MUST NOT 규칙을 제공합니다.
  - `get_page_layout`: 페이지 구조 트리와 자동 레이아웃 힌트를 제공합니다.
- M3 범위의 Figma 임포트를 추가했습니다.
  - `import_figma`가 Figma REST API에서 파일을 가져와 Penpot 구조로 변환합니다.
  - Figma REST API v1 클라이언트와 `convertFigmaToPenpot` 변환기를 추가했습니다.
  - Auto Layout을 Flex 레이아웃으로 매핑하고, RGBA 색상을 hex로 변환하며, 주요 노드 타입을 매핑합니다.
- Penpot API 연동을 보강했습니다.
  - 3회 재시도와 지수 백오프, 30초 타임아웃을 적용했습니다.
  - `commitChanges`로 변경사항을 원자적으로 커밋합니다.
- CLI에 `--help`, `--version`, 도구 목록 표시를 추가했습니다.
- 멀티스테이지 Dockerfile과 GitHub Actions CI를 추가했습니다. CI는 테스트와 태그 릴리스를 지원합니다.
- 테스트를 34개로 확장했습니다(compressor 10개, tools 11개, converter 13개).
- Figma 파일 포맷 리서치와 Figma+Claude Design 비교 벤치마크 문서를 추가했습니다.
